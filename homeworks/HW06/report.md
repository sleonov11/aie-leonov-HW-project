# HW06 – Report

## 1. Dataset

Какой датасет выбран: `S06-hw-dataset-02.csv`  
Размер: 18 000 строк × 37 признаков (`f01`–`f35`, `x_int_1`, `x_int_2`) + целевая переменная `target`  
Целевая переменная: `target` (бинарная классификация)  
- Класс 0: 73.74%  
- Класс 1: 26.26%  

Все признаки числовые (`float64`). Пропусков нет.

## 2. Protocol

Разбиение: `train/test = 80%/20%`  
- Train: 14 400 образцов  
- Test: 3 600 образцов  
- `random_state=42`, `stratify=y` — для воспроизводимости и сохранения пропорций классов

Подбор гиперпараметров:
- Только на **train** через `GridSearchCV`
- Кросс-валидация: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`
- Оптимизация по метрике: **ROC-AUC**

Финальная оценка:
- Выполняется **один раз** на **test** после подбора

Метрики качества:
- **Accuracy** — общая точность
- **F1-score** — учитывает дисбаланс классов (precision + recall)
- **ROC-AUC** — основная метрика, устойчива к дисбалансу и оценивает качество ранжирования

> **Average Precision не использовалась** — в коде не вычислялась.
